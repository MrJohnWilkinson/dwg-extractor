# Claude Code Commands

- All commands must use ONLY the headings options listed under `Headings`.
- `Claude Code Commands` DON'T REQUIRE that ALL headings are used.  eg.  `.claude/commands/bug.md` and `.claude/commands/chore.md` only use SOME of the headings.  

# Headings

```
Metadata
# Title (The title is the only heading that can be renamed.  eg.  "# Chore Planning" or "# Bug Planning")
## Purpose
## Variables
## Instructions
## Relevant Files
## Codebase Structure
## Workflow
## Expertise
## Template
## Examples
## Report
```
