# Report Generation

## Purpose

Generate a concise analysis report in the `ai_output/` directory based on the provided topic. Follow the `Instructions` to create the report using the exact specified markdown `Report Format`.

## Variables

REPORT_TOPIC: $ARGUMENTS (required)

## Instructions

- IMPORTANT: You're creating a concise, scannable report based on the `Report Topic` provided.
- Create the report in `ai_output/NNN-*.md` where NNN is the next 3-digit number (e.g., if highest is ai_output/002-foo.md, use ai_output/003-new-name.md).
- Use the `Report Format` below to create the report.
- Research the codebase or gather information as needed to provide accurate, relevant analysis.
- IMPORTANT: Replace every <placeholder> in the `Report Format` with the requested value.
- Keep the report concise and scannable - avoid verbose explanations.
- The `Table Summary` section is REQUIRED and should condense key information into an easily digestible format.
- Use appropriate headings based on the report topic - not all sections may be needed.
- Focus on clarity and actionable insights.
- Use your reasoning model: THINK HARD about what information is most valuable for this report.

## Report Format

```md
# <Report Title>

## Executive Summary
<2-3 sentence overview of the report's key findings or purpose>

## Table Summary
<single scannable markdown table that condenses the key information. Format depends on report topic but should make data easily digestible at a glance>

## Relevant Files
<find and list the source files (including the path) that are relevant to the report and describe why they are relevant in bullet points.>

## <Section Heading 1>
<relevant content organized under appropriate headings based on report topic>

## <Section Heading 2>
<additional sections as needed>

## Simple list summary
<a simple >

```

- Include a path to the report you created in the `ai_output/*.md` file.
